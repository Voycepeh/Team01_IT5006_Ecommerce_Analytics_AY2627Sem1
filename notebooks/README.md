# Notebooks

Use this folder for exploratory analysis, experiments, visual investigation, and notebook-based project work.

## Conventions

- Use clear, descriptive notebook names.
- Keep notebooks reproducible from repository data and code where possible.
- Avoid machine-specific absolute paths.
- Move reusable logic into `src/` when it becomes stable enough to share across notebooks.
- Do not leave misleading outputs that no longer match the current code.
- Record important assumptions and analytical decisions.
