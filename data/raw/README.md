# Raw Data

Place the original Olist dataset files provided through the IT5006 Canvas Week 1 module in this folder after cloning the repository.

These raw data files are intentionally not committed to GitHub. The `.gitignore` keeps files in `data/raw/` local while preserving this README.

Expected files include the lecturer-provided Olist CSVs such as customers, orders, order items, payments, reviews, products, sellers, geolocation, and product category translation files.

Do not modify the original raw files. Use notebooks or scripts to create cleaned or transformed outputs elsewhere when needed.
